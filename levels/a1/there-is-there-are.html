There Is / There Are

Say what exists, without naming who owns it.

ObjectivesExplanationRulesExamplesCommon MistakesPracticeSummaryRelated

Introduction

“There is” and “there are” announce that something exists — useful for describing a room, a city, or anywhere you want to list what's present.

By the end of this lesson you can…

  • Use “there is” with singular and uncountable nouns
  • Use “there are” with plural nouns
  • Form negatives and questions with there is/are

Explanation

Explanation

There is introduces one thing, or something uncountable: There is a book on the table. There is water in the glass. There are introduces more than one thing: There are three books on the table.

The negative adds “not” (there isn't / there aren't), and the question simply swaps the order: Is there a bank near here? Are there any seats left?

Grammar Rules

The Rules

  • There is → singular + uncountable nouns
  • There are → plural nouns
  • Negative: There isn't / There aren't
  • Question: Is there…? / Are there…?

Examples

See It in Action

  • There is a cat in the garden.
  • There are five students in the room.
  • There isn't any milk in the fridge.
  • Are there any questions?
  • There is a lot of traffic today.

Common Mistakes

Watch Out For

AvoidThere is three books on the table.

Use insteadThere are three books on the table.

“Three books” is plural, so it needs “there are,” not “there is.”

AvoidThere are a problem.

Use insteadThere is a problem.

“A problem” is singular, so it needs “there is.”

AvoidIs there any apples?

Use insteadAre there any apples?

“Apples” is plural, so the question needs “are there,” not “is there.”

Tip

Check the noun right after “there is/are” — singular or uncountable takes “is”; plural takes “are.”
